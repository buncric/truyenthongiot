# Nội dung có từ trước

`uart-truoc-khi-phan-loai/` là nguyên trạng thư mục BTH3_SPI_I2C cũ, thực tế chứaUART. Các đường dẫn tương đối trong README cũ vẫn áp dụng bên trong thư mục lưu trữ đó. README-truoc-khi-phan-loai.md giữ nội dung trang chính trước khi tổ chức lại.

Project UART mới ở../BTH02_UART; SPI/I²C đúng đề ở../BTH03_SPI_I2C. Các thư mục gốc1.2,code,images,BareMinimum và New Project.pdsprj vẫn được giữ.
